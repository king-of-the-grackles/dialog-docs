# Data Sources

Dialog connects to multiple data sources through the Model Context Protocol (MCP) to provide comprehensive research coverage. Each source specializes in different types of intelligence.

## Available sources

### Reddit Research
The primary data source. Dialog can:
- Discover relevant subreddits for any topic
- Fetch posts and comments with full context
- Analyze sentiment and engagement patterns
- Search across communities using semantic matching

### Web Search & Scraping
Dialog can search the broader web and scrape specific pages for additional context:
- Search engine results for any query
- Full page content extraction from URLs
- Structured data extraction from websites

### Social Media Intelligence
Access insights from additional social platforms:
- Post and comment data from major platforms
- Profile and engagement metrics
- Trending content and discussions

## How sources work together

When you ask a question, Dialog intelligently routes your query to the most relevant sources. For example:

- A question about "Reddit sentiment on X" primarily uses the Reddit Research source
- A question about "what does Company Y's pricing page say" uses web scraping
- A broader market research question may combine Reddit, web, and social media data

## Managing your sources

In **Settings**, you can enable or disable specific data sources. This lets you:
- Focus research on specific platforms
- Control which tools Dialog uses for your queries
- Customize the research experience to your needs
