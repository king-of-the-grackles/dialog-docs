## The research flow

Every research interaction follows the same path through Dialog's systems, from your initial question to a complete, sourced answer.

<Steps>
  <Step title="You ask a question">
    Type a natural language query in the research chat. Your question can be broad ("What do people think about AI coding tools?") or targeted ("What are the top complaints about Linear's mobile app on Reddit?").
  </Step>

  <Step title="Agent selects relevant data sources">
    Based on your query, the agent determines which [tools](/core-concepts/tools/overview) to use. A question about Reddit sentiment routes to Reddit Research. A question about a competitor's social presence might hit multiple social media sources at once.
  </Step>

  <Step title="Tools gather information">
    The selected tools execute in parallel where possible — fetching posts, scraping pages, pulling social data, or querying connected apps. Each tool returns structured results back to the agent.
  </Step>

  <Step title="Agent synthesizes findings">
    The agent analyzes the raw data, identifies patterns and themes, and assembles a structured research brief. Citations link back to original sources so you can verify anything.
  </Step>

  <Step title="Results stream in real time">
    You see the entire process unfold live — tool activity, the agent's reasoning, and the final output all stream back as they happen. No waiting for a batch result.
  </Step>
</Steps>

## System boundaries

Each agent in Dialog operates within its own isolated environment. Understanding these boundaries helps you design better research workflows.

**Agent isolation.** Every agent has its own persistent workspace environment with dedicated storage, tool configuration, and [skills](/core-concepts/skills). One agent cannot access another agent's workspace, files, or conversation history. This means you can run multiple agents for different projects without any cross-contamination.

**Tool configuration is per-agent.** Each agent can have different [tool preferences](/core-concepts/tools/tool-preferences) — one agent might have social media sources enabled while another only uses Reddit and web search. You control this at the agent level or override it per session.

**Scheduled tasks share the workspace.** When you set up [scheduled research](/core-concepts/scheduling), those tasks run in the same workspace as your chat sessions. This means scheduled tasks can read and write the same files, use the same skills, and build on the same memory your agent has from interactive conversations.

<Info>
Agents are fully independent by design. If you need to share research between agents, export results via [channels](/core-concepts/channels) or use connected apps to store findings in shared tools like Notion or Google Docs.
</Info>
